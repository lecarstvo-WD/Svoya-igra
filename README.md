# Своя игра — Логика 7 класс

Интерактивная игра на HTML/CSS/Bootstrap/JS. Без бэкенда — работает полностью в браузере.

## Запуск

### Локально (через локальный сервер)
```bash
python3 -m http.server 8000
```
Откройте http://localhost:8000

### Или просто откройте index.html
Можно просто двойным кликом открыть index.html — встроенные вопросы подгрузятся автоматически.

## Деплой на GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Settings → Pages → Source: Deploy from branch → main → /root
4. Сайт будет доступен по адресу: https://ваш-ник.github.io/название-репозитория/

## Структура
```
index.html       — главная страница
css/style.css    — стили
js/game.js       — игровая логика
questions.json   — база вопросов (5 категорий × 5 вопросов)
.nojekyll        — чтобы GitHub Pages не ломал структуру
```

## Как добавить свои вопросы
Откройте questions.json и редактируйте. Формат:
```json
{
  "categories": [
    {
      "name": "Название категории",
      "questions": [
        {"points": 100, "question": "Текст вопроса", "answer": "Текст ответа"},
        ...
      ]
    }
  ]
}
```
